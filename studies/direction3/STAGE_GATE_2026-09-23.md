# 方向 3 阶段冻结结果与准入门槛（2026-09-23）

## 阶段裁决

目前可复核的稳定版本是：固定 TP-UIC、sigma-point 残差协方差、目标邻域 GLRT、预先固定的两 UAV 归一化和、最终统计量 split-conformal 门限。它不是已完成的感知关联或通信受限相关性感知融合算法。TP-UIC 相对常规 IC 的检测收益、关联相对 SINR Top-K 的收益和多目标全局虚警率均尚未成立，不得作为论文贡献陈述。

## 已复核结果

真实接收链，M=6、Q=3 场景中的目标 1，UAV 0/1，RCS 0.05 m²，直达增益 +30 dB。20 个独立场景用于最终 H0 校准，另 40 个独立场景用于测试；每场景一条联合 H0/H1 记录，融合子集与规则在校准前固定。

| 方法 | 测试 AUC | 测试虚警 | 测试检出 |
|---|---:|---:|---:|
| UAV 0 单独 | 0.575 | 0/40 | 4/40 |
| UAV 1 单独 | 0.789 | 0/40 | 4/40 |
| 固定 UAV 0+1 归一化和 | 0.745 | 0/40 | 3/40 |

融合门限是 20 个校准 H0 统计量的最大值 4.754。在未来场景可交换且融合规则预先冻结时，**该固定单目标告警**的边际 PFA 上界为 1/21=4.76%。测试 0/40 次虚警不能证明实际 PFA 小于 5%；融合比最佳单 UAV 少检出 1 个场景，故这只是校准接线验证。原始结果在 `data/dd_scope_scene_fixed_fusion_conformal/result.json`，重算入口是 `tools/run_fixed_fusion_conformal.py`。

### 固定 3-bit 标量报告的可重复接口试验

将两个本地 GLRT 分数分别按本地复秩归一化，使用固定的 [0,8] 均匀最近邻 3-bit 量化器；两条报告的标量 payload 共 6 bit/目标，不计头部、编码、误包或时延。量化器与融合规则均不使用 test 分数拟合，最终门限在量化后的 20 个独立 calibration 场景上重定。结果：门限 4.571，边际 PFA 排名上界仍为 1/21=4.76%；40 个 test 场景中虚警 0、检出 3，AUC 从未量化的 0.745 降到 0.711。test 的 80 条本地 H1 报告中有 1 条超过量化上界并截断，H0 无截断。这个数据复用的接口试验只说明量化会影响排序而没有在此样本上改变严格门限处的检出数，不是独立确认的通信性能结论。机器结果为 `data/quantized_fixed_fusion_3bit/result.json`，入口为 `tools/run_quantized_fixed_fusion.py`，相关测试 5/5 通过。

## 完整主线的阻断原因

1. 旧关联数据每目标每 split 为 3 个独立场景 × 2 次噪声实现，不是 6 个独立场景。场景级 5% split-conformal 非平凡门限至少需要 19 个独立 H0 校准场景；关联子集、H0 协方差和融合权重还需在另一组训练场景上确定。
2. 旧关联实验未构造冻结后的多目标最终告警 `max_q T_q`。局部或单目标 5% 门限不能冒充网络全局 family-wise 5%。
3. 固定融合上传未量化实数分数，尚未指定 payload、头部、目标索引、块长、编码率、误码/丢包与时延。K=2 只约束接收 UAV 数，不等于满足 `B(S) <= B_max`。量化和链路机制须先冻结，再对**实际收到的报文**校准最终门限。
4. +30 dB/0.05 m² 是弱目标强干扰压力点，最佳单 UAV 也只检出 4/40。不得靠降低门限、改变功率/RCS/looks 后沿用原 5% 保证；变更工作点须预先声明，并保留此压力点作为失败区间。
5. 历史 RCS 5 m²“真实残差全局虚警”确认集的 16/16/16 条记录，分别仅来自 8/8/8 个独立场景；同场景两次噪声实现被按行计入门限和检出率，且尺度/量化截断范围在门限数据上拟合。其 10% 门限是探索性经验阈值，不是场景级 conformal 保证。复核输出为 `data/global_pfa_real_tpuic_rcs5_confirm/scene_count_audit.json`。这解释了为何它不能直接接替当前固定双 UAV 的有效场景级校准。
6. 更根本的是 `run_tpuic_receiver_benchmark.py` 按 `(receiver,target)` 独立播种，并为每个被测目标 q 建立“只移除 q、其他目标仍在”的 H0。不同 q 的行不是同一个物理接收观测，且没有“所有目标均不存在”的全局 H0。因而不能通过按 `scene_id` 拼接旧记录构造 `max_q T_q`，也不能仅靠增加场景数修复。2026-09-23 的 2 场景 × 3 UAV × 2 目标试跑仅用于核查运行成本与这一数据契约，AUC 0/1 不作性能结果。今后 benchmark manifest 显式标记 `multi_target_joint_alarm_compatible=false`。

## 联合双目标全局告警：阶段 v0.2 pilot（2026-09-23）

已新增 `tools/run_joint_global_alarm.py`，并完成一次预先固定参数的真实 TP-UIC 试验：M=6 场景中固定接收 UAV {0,1}，Q=2 个候选目标，均为 RCS 0.05 m²；+30 dB 直达干扰、sigma-point 残差协方差、3×3 邻域 GLRT、固定 [0,8] 3-bit 均匀量化，每场景的两个 UAV 各上报两个目标分数，标量 payload 共 12 bit。发射功率、波形、looks、几何生成器及接收算法未做扫描。一个场景/接收 UAV 只生成一次物理观测；H0 移除两个候选目标，H1 两者同时存在，两个检测器处理同一观测。20 个独立场景只校准 `max_q T_q`，另 20 个独立场景只测试。

| 终点 | 结果 |
|---|---:|
| 全局 H0 校准门限（20/20 最大值） | 4.571 |
| 场景可交换下全局 H0 的边际 PFA 界 | 1/21 = 4.76% |
| 测试全局 H0 虚警 | 1/20 |
| 测试目标 0 检出 | 2/20 |
| 测试目标 1 检出（worst） | 0/20 |
| 测试目标 0/1 AUC（量化后） | 0.613 / 0.571 |

这是首个**同一物理观测、同一全局无目标 H0**上的多目标最终门限 pilot，修复了旧数据不可拼接的问题。它只保证全局无目标 H0 下“任一目标告警”的边际 PFA；没有证明部分目标存在时对其余空目标的强 family-wise 控制，也没有证明跨时段残差漂移下的保证。20 个测试场景的 1/20 虚警计数不代表真实 PFA 恰为 5%。在当前量化、强干扰和弱目标工作点，最差目标完全没有检出；校准集全局 H0 仅有 3 个不同量化分数，门限粒度也是活动限制。不能从这些数值单独归因于物理回波、量化或协方差模型，更不能称为合作/关联增益。

机器记录为 `data/joint_global_alarm_20cal20test/result.json`，其 `records` 每场景只有一条共同的双目标 H0/H1 分数向量。前置两场景试跑只验证接口，不计入正式 pilot。通信侧 12 bit 仅是 payload 下界，未计头部、信道编码、链路误码与时延，因此不宣称通信链路可行；感知侧没有增加功率或 looks 来救援检出率。

接下来的准入顺序是：先在同一联合观测器上预先记录未量化与量化本地分数，用场景级独立测试区分信息损失；然后定义含报头/编码/可靠性的预算，并为 UAV 关联留独立训练场景。只有固定子集的多目标全局门限稳定后，才用不枚举的候选法比较最佳单 UAV、SINR Top-K 与相关性感知法。此处不得因为 worst PD=0 就在同一测试集上调位数、RCS、门限或量化截断。

## 同场景归因：阶段 v0.3（2026-09-23）

在完全相同的 40 个场景、随机种子和接收配置上，新增记录每 UAV/目标的**未量化**局部 GLRT 分数，保留原 3-bit 报告。对两架 UAV 各自和固定等权双 UAV，在未量化与 3-bit 两种报告下，分别使用同一批 20 个 H0 校准场景为 `max_q T_q` 定 5% 目标的最终门限，并仅在另 20 个场景评估。新增记录与 v0.2 的 40 条量化分数、门限及检出数逐项复现；不是换场景后做横向对比。**这批 test 在 v0.2 已被查看，故 v0.3 仅用于配对归因，不能当作新的独立确认或据此选权重。**

| 固定统计量 | 全局 H0 虚警 /20 | 目标 0 检出 /20 | 目标 1 检出 /20 | 目标 0/1 AUC |
|---|---:|---:|---:|---:|
| UAV 0，未量化 | 0 | 1 | 0 | 0.760 / 0.648 |
| UAV 1，未量化 | 0 | 2 | 0 | 0.448 / 0.573 |
| UAV 0+1 等权，未量化 | 0 | 2 | 0 | 0.565 / 0.623 |
| UAV 0，3-bit | 0 | 1 | 0 | 0.608 / 0.565 |
| UAV 1，3-bit | 0 | 2 | 0 | 0.560 / 0.500 |
| UAV 0+1 等权，3-bit | 1 | 2 | 0 | 0.613 / 0.571 |

每行在场景可交换、统计量事先固定的条件下，均有相同的 `1/21=4.76%` **全局无目标 H0** 边际 PFA 排名界；不同臂的数值门限不同。测试 0/20 或 1/20 的差别不足以断定真实 PFA 谁更低。零检出在未量化单/双 UAV 中仍存在，说明 3-bit 截断与量化**不是当前 worst PD=0 的充分解释**。目标 0 的未量化 UAV 0 AUC 0.760，等权融合后 0.565，提示固定等权融合可能稀释有用排序；但它在严格门限下仍只检出 1/20，不能凭 AUC 在测试集上选择它。目标 1 的未量化双 UAV AUC 0.623 而 PD 0/20，说明仍有一定排序信息，但在当前校准极值门限与工作点下没有可靠尾部检出；20 个场景不足以证明“物理上完全不可探测”。

该归因试验只改变**报告精度与固定融合口径**，未改变功率、时频占用、几何、接收机或虚警目标。未量化臂是通信不受限的诊断参考，不是可部署方法或逐指标的数学上界；3-bit 每场景 12-bit 标量 payload 仍未含报头、纠错编码与链路误包。逐场景原始分数及所有门限在 `data/joint_global_alarm_paired_20cal20test/result.json`。当前最合理的下一步不是改量化位数，而是以新独立 train 场景学习**受约束、H0 相关性感知**融合权重，再用全新 calibration/test 场景核对最差目标 PD；若无稳定改进，应停止把合作融合列为贡献。

## 下一版的最小非枚举协议

- 固定发射功率、波形/带宽、CPI/looks、几何、TP-UIC 和 GLRT；不通过增加感知能量或占用更多时频资源制造关联收益。固定 K、总上报 bit 与时延预算，包含每 UAV 报告的 payload 和协议开销，并记录误包。
- 三个场景级独立数据块：train 学子集、H0 协方差和融合权重；calibration 只定最终门限；test 只评估。共同场景中所有 UAV/目标配对；同场景多次噪声实现只用于聚类分析，不能增加场景级 conformal 样本数。
- 联合接收观测生成器已提升为正式领域模块 `isac_sim.receiver.joint_observation`：每 UAV/场景/实现只生成一对共享的全局 H0/H1 物理观测，所有 q 的 GLRT 仅切换检测目标索引，不重抽观测。后续实验必须复用该契约；不得把现有逐目标排除式 benchmark 的行拼接替代它。
- 不枚举子集：比较最佳单 UAV、可部署 SINR Top-K、独立信息贪心与 H0 相关性贪心；同一 K、bit/时延预算。真值辅助 post-IC SINR 只能是诊断上界。记录实际候选评估数。
- 对每种已冻结方法，以量化/丢包后的最终多目标分数 `T=max_q T_q` 在独立 H0 calibration 上定门限，再在 test 报最差目标 PD、全局 PFA、置信区间及通信成本。各方法可有各自门限，但必须比较同一目标 PFA。
- 停止规则：独立 H0 校准场景不足 19，或通信成本未定义，则不发布 5% 全局 PFA/PD 对比；若独立测试中无法稳定超过最佳单 UAV/SINR，降级关联创新主张，不再靠门限、功率或 looks 扫描救援。正式论文的 10^-3 全局 PFA 需要远多于本 pilot 的场景数。
