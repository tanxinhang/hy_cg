# 固定预算融合权重 pilot：冻结协议

## 问题与工作点

检验在 v0.3 的双 UAV、双目标、3-bit/报告工作点下，训练集上学到的受约束权重是否能在**相同最终全局 H0 虚警目标**下提高最差目标检出率。该实验不学习 UAV 子集，不改 TP-UIC、残差协方差、邻域 GLRT、功率、looks、几何生成规则、直达增益、RCS 或量化区间。

固定条件：M=6 场景，Q=2 同 RCS 0.05 m²，接收 UAV {0,1}，直达增益 +30 dB；每个 UAV 对每个目标上报固定 [0,8] 均匀量化的 3-bit 标量。双 UAV 共 12-bit/场景的标量 payload，仅为通信成本下界；协议开销、编码、丢包与时延仍不在本 pilot 内。

## 场景级拆分与规则

- 新主种子 20260929，依次 20 个 train、20 个 calibration、20 个 test 独立场景，每场景每 UAV 只生成一次联合物理观测。H0 无候选目标，H1 两目标同时存在。任何测试分数均不参与权重或门限学习。
- 权重只在 `(w0,w1)=(0,1),(0.25,0.75),(0.5,0.5),(0.75,0.25),(1,0)` 中选。train 目标是各目标的一侧均值差平方除以 H0 方差后的**最小值**；H0 协方差固定做 70% 对角收缩，并加 `(8/7)^2/12` 对角方差下限以避免量化平局导致除零。并列时选最接近等权者。
- 固定比较臂：UAV 0、UAV 1、等权双 UAV、train 选择的双 UAV 权重。每臂在 calibration 的场景级 `max_q T_q` H0 分数上独立取 split-conformal 20/20 极值门限，严格 `>` 才报警；目标全局无目标 H0 PFA=0.05，对新可交换场景的边际排名界 1/21。test 只统计全局虚警、各目标检出和 AUC。
- 未量化臂只作诊断参考，不占 12-bit 报告预算，也不参与权重选择。报告所有候选的 train 效用，但不据 test 结果重选候选。

## 判定边界

主要终点是 `min_q P_D,q`，比较时同看经验全局虚警、各目标 AUC 与成本。20 个 test 场景只能给出粗粒度 pilot：单次检出对应 5 个百分点，不能据此声称稳定统计优势。若最差目标仍零检出，则先停止继续扩权重网格；若出现增益，也必须在新主种子的更大独立测试批次确认后，才能把融合视为贡献。此实验只控制全局**无目标** H0，不提供部分目标存在时的强 family-wise 保证或漂移下保证。

## 冻结运行结果与裁决

新主种子按预定规则生成了 20/20/20 个独立 train/calibration/test 场景。训练目标在五个固定候选中选出 `(w0,w1)=(0.5,0.5)`，最差目标训练 deflection 为 0.329；因此 proposed 实际退化为等权双 UAV，**没有学到相对基线的新融合策略**。每个臂仅用 calibration H0 的 `max_q T_q` 第 20/20 顺序统计量定门限；条件为未来场景与 calibration 可交换时，每臂的全局无目标 H0 边际排名界均为 1/21=4.76%。

| 固定臂 | 测试全局虚警 /20 | 目标 0 检出 /20 | 目标 1 检出 /20 | 目标 0/1 AUC |
|---|---:|---:|---:|---:|
| UAV 0，3-bit | 0 | 0 | 0 | 0.425 / 0.575 |
| UAV 1，3-bit | 0 | 0 | 2 | 0.400 / 0.558 |
| 等权双 UAV，3-bit | 0 | 0 | 1 | 0.351 / 0.596 |
| 训练权重双 UAV，3-bit | 0 | 0 | 1 | 0.351 / 0.596 |
| 等权双 UAV，未量化诊断 | 1 | 1 | 5 | 0.428 / 0.578 |

同一测试场景中，未量化双 UAV 独有的检出为目标 0 的 1 个、目标 1 的 4 个；反向（仅 3-bit 检出）为 0。train、calibration、test 的局部分数均未超过固定量化上界 8，故不是上界饱和，而是量化步进与极值门限共同造成的尾部损失。calibration 的量化全局 H0 仅有 3 个不同取值，使严格 `>` 决策粗糙。另一方面，目标 0 未量化 AUC 只有 0.428，说明其局部分数本身缺少稳定排序信息；增加报告精度也不构成全目标解决方案。

该结果触发预定停止规则：**不扩大融合权重网格，不宣称合作融合收益**。与上一批主种子 20260926 的同配置归因相比，目标 1 的未量化双 UAV 检出由 0/20 变为 5/20，3-bit 由 0/20 变为 1/20，跨批次波动明显；因此即便有个别正向数值，也不能称稳定性能收益。下一轮若继续，应先审核目标 0 的本地统计量与几何可探测性，再以独立训练场景评估**固定总 bit 预算内**的检测感知量化，而不是靠调功率、looks、全局 PFA 或测试集阈值救援。

逐场景结果：`data/joint_weight_train20_cal20_test20/result.json`。通信成本仍只包括双 UAV × 双目标 × 3-bit = 12-bit 标量 payload，未含编码、头部、误包、时延；本 pilot 未通过通信链路可行性门槛，也不代表关联优化。
