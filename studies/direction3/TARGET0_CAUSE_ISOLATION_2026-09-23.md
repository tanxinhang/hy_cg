# 目标 0 探测低性能的同场景因果隔离（2026-09-23）

## 结论

当前最主要的**可定位、可改进**问题是目标状态信念与真实回波流形不符，导致实际目标模板没有稳定抓住 H1 增量；仅靠修正联合 H0 协方差或增加保护目标数不能解决。即使给检测器不可用的真值模板，目标 0 的 AUC 也只有约 0.63，说明当前工作点的弱回波/噪声与场景异质性仍有不可忽略的剩余限制。固定 3-bit 报告及全局极值门限又使有限的未量化信息难以转成严格门限检出。不能把所有低检出归为单一 bug，也不能宣称物理上绝无可能。

## 证据链

全部比较沿用同一批 20 个独立测试场景（40–59）、同一 H0/H1 观测、同一 TP-UIC 结果；以下 AUC 均为两接收 UAV 未量化分数之和，仅作定位，不作部署性能。真值目标模板和理想直达信道消除均为不可部署 oracle。

| 目标 0 检测信息 | 联合 AUC | 同场景 H1−H0 分数中位数 |
|---|---:|---:|
| 原信念 DD 邻域 GLRT | 0.428 | −0.240 |
| 信念状态轴向 9 模板，修正联合 H0 协方差 | 0.520 | −0.114 |
| **仅换真值目标字典；TP-UIC 与原信念残差协方差不变** | **0.630** | **+0.330** |
| 再换真值口径协方差 | 0.633 | +0.336 |
| 再换理想直达信道消除 | 0.678 | +0.136 |

真值目标字典相对原基线提升 AUC 约 0.203；同场景配对 bootstrap（5000 次，按场景重抽样）的探索性 95% 区间约为 +0.045 至 +0.395。相对已改进的轴向几何模板，提升约 0.110，其区间约为 −0.025 至 +0.283，故不能断言这个有限样本上“真值模板必然优于几何模板”。真值协方差仅增加约 0.003；理想直达信道消除再增加约 0.045，其对应探索性区间跨 0。该分解支持“原信念模板/目标状态失配是首要可见瓶颈，协方差口径不是主因，剩余直达干扰是次要但非零因素”，但不是精确的归因百分比。

TP-UIC 逐目标回波功率存活中位数为目标 0 的 0.99878，直达抑制中位数约 30.78 dB，排除“对消器严重抹掉弱目标”和“完全未抑制直达干扰”。原基线目标 0 在两接收 UAV 上的同场景 H1−H0 本地分数中位数分别约为 −0.036 和 −0.019，联合为 −0.240；损失发生在量化之前。实际信念几何模板虽使 AUC 升至 0.520，最终 3-bit 严格全局门限仍为 0/20 检出；因此量化/极值门限是第二层瓶颈，不能当作原始分数缺少区分度的唯一原因。

## 不能越过的推断边界

- 真值字典改变被测目标和其他目标的 nuisance 模板，是“目标状态/回波流形知道真值”的 oracle，不是可直接实现的检测器。下一步应校验跟踪误差分布、构造不泄露真值的相关路径联合模板，并在另一主种子上复核。
- 理想直达信道是诊断上界，不满足实际接收条件。20 个测试场景的 AUC 和配对 bootstrap 仍不构成稳定统计优越性证明；要做结论需新独立测试批次。
- 此处没有为 oracle 重定全局虚警门限，因此不报告 oracle 检出率，也不宣称其满足给定 PFA。真实系统仍以 `CODE_CONTRACT_ABLATION_2026-09-23.md` 的 3-bit 全局告警结果为准。
