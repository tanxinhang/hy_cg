## Rebuild

From `D:\Desktop\conference`:

```powershell
python .\tools\make_target_local_v1_paper_figs.py
latexmk -pdf -interaction=nonstopmode -halt-on-error -cd ".\Conference-LaTeX-template_10-17-19\Communication-Constrained Soft-Information Fusion for Multi-UAV OTFS-ISAC Cooperative Sensing.tex"
```

The plotting script exports an editable SVG master, a PDF used by LaTeX, and a
600-dpi PNG for each data figure. The manuscript PDF is generated in this
folder. The prospective 4.693 ms parallel delay is a no-interference slot lower
bound; the implemented V1 latency is the serial value 12.793 ms (MC=1000 main)
or 12.971 ms (MC=100 fusion ablation).
