# 最终系统模型与论文仿真代码

## 1. 系统对象

考虑一个多 UAV 协同 OTFS 感知系统。系统包含 `M` 个 UAV 和 `Q` 个地面目标。

- UAV 集合：`J = {1, ..., M}`
- 目标集合：`Q = {1, ..., Q}`
- 二元任务分配变量：`z_{j,q} in {0,1}`
- `z_{j,q}=1` 表示 UAV `j` 被分配观测目标 `q`

每个 UAV 既可作为接收端，也可作为协作双基地链路中的发射端。核心研究对象不是完整标准 OTFS modem，而是任务边之间的 delay-Doppler-angle collision 对检测和跟踪性能的影响。

## 2. 双基地 delay-Doppler 模型

对发射 UAV `i`、接收 UAV `j`、目标 `q`，双基地传播时延为：

```text
tau_{i,j,q} = (||p_q - p_i|| + ||p_q - p_j||) / c
```

双基地 Doppler 为：

```text
nu_{i,j,q}
= [ (v_q - v_i)^T e_{i,q} + (v_q - v_j)^T e_{j,q} ] / lambda
```

其中：

```text
e_{i,q} = (p_q - p_i) / ||p_q - p_i||
e_{j,q} = (p_q - p_j) / ||p_q - p_j||
lambda = c / f_c
```

映射到 OTFS delay-Doppler 网格：

```text
l = tau / Delta_tau
k = nu / Delta_nu
```

这里的 `l` 和 `k` 是分数 delay-Doppler 中心，不在该步骤取整。OTFS 帧结构为：

```text
N_tau : delay bins / subcarriers
N_nu  : Doppler bins / OTFS symbols
Delta_tau = 1 / (N_tau * Delta_f)
Delta_nu  = 1 / (N_nu * T_sym)
T_sym      = 1 / Delta_f
```

分数 Doppler 造成的 inter-Doppler interference 用 Dirichlet 泄漏核描述：

```text
D_N(x) = sin(pi*x) / [N * sin(pi*x/N)]
p_N(a; c) = |D_N(a - c)|^2 / sum_b |D_N(b - c)|^2
```

其中 `c` 是分数 DD 中心，`a,b` 是环形 DD bin。整数 Doppler 时 `p_N` 退化为近似 Kronecker delta；分数 Doppler 时能量按 Dirichlet 旁瓣泄漏到相邻 Doppler bins。

## 3. 任务约束

任务分配矩阵 `Z = [z_{j,q}]` 满足：

```text
sum_q z_{j,q} <= K_U
K_T_min <= sum_j z_{j,q} <= K_T_max
z_{j,q} <= v_{j,q}
```

其中 `v_{j,q}` 是可见性约束，由距离、视场、SNR 和 Doppler alias 共同决定。

## 4. DD-angle collision 模型

对受保护任务边 `(j,q)`，另一个任务边 `(i,q')` 会在接收 UAV `j` 上造成跨目标干扰，其中 `q' != q`。

未归一化碰撞强度：

```text
C_{(i,q')->(j,q)}
= G_{i,j,q'} * Omega_DD(i,j,q',j,q) * Omega_theta(j,q',q)
```

其中：

```text
G_{i,j,q'}       : 双基地传播、天线和 RCS 增益
Omega_DD         : 源目标 Dirichlet DD 泄漏进入受保护 DD 支撑窗口的能量比例
Omega_theta      : 两个目标在接收 UAV 视角下的角度重叠
```

受保护窗口只在定义物理 bin 集合时取整：

```text
W(j,q) = {(a,b): a in round(k_{j,j,q}) +/- h_k,
                 b in round(l_{j,j,q}) +/- h_l}
```

DD 泄漏比例为：

```text
Omega_DD(i,j,q' -> j,q)
= sum_{(a,b) in W(j,q)}
    p_{N_nu}(a; k_{i,j,q'})
  * p_{N_tau}(b; l_{i,j,q'})
```

这不是盒式 overlap。即使两个目标 DD 中心不落入同一保护窗口，只要分数 Doppler/Delay 旁瓣泄漏进入 `W(j,q)`，`Omega_DD` 仍然为正。

归一化碰撞强度：

```text
Cbar_{(i,q')->(j,q)}
= C_{(i,q')->(j,q)} / (S_{j,q} + sigma_n^2)
```

有效碰撞判定：

```text
G > g_min
Omega_DD > dd_min
Omega_theta > ang_min
Cbar > c_norm_min
```

## 5. 优化目标

最终任务分配目标为：

```text
max_Z  sum_{j,q} z_{j,q} U_{j,q}
     + mu * D_theta(Z)
     - lambda_col * sum Cbar
     - xi * S(Z, Z_prev)
```

其中：

```text
U_{j,q}       : UAV-target 可观测收益
D_theta(Z)   : 同一目标的多 UAV 角度多样性
sum Cbar      : 归一化 DD-angle collision 总成本
S(Z,Z_prev)  : 相邻帧任务切换成本
```

代码位置：

```text
gate_otfs_collision/assignment.py
  objective()
  assignment_collision_aware_greedy()
```

## 6. 检测仿真模型

对每条任务边 `(j,q)`，受保护 DD 支撑窗口中的信号为：

```text
y = s_self + s_coop + i_cross + n
```

其中：

```text
s_self  : UAV j 对目标 q 的自回波
s_coop  : 其他 UAV 对同一目标 q 的协作双基地回波
i_cross : 其他目标 q' 的任务边干扰
n       : 复高斯噪声
```

默认检测器为非相干 matched-filter bank。门限由 H0 Monte Carlo 样本确定：

```text
Pfa = Pr(T(y0) > gamma)
Pd  = Pr(T(y1) > gamma)
```

代码位置：

```text
gate_otfs_collision/detection.py
  evaluate_assignment_full_link()
  _detect_noncoherent_matched_components()
```

## 7. 论文应仿真的核心实验

建议论文主实验使用以下四组：

```text
Experiment 1: Gate 1
验证 DD-angle collision 是否导致 OTFS 检测退化。

Experiment 2: Proxy validation
验证优化代理 Cbar 是否能预测真实检测损失 Delta Pd。

Experiment 3: Gate 2
验证自然多 UAV/多目标部署中是否出现低密度 collision，以及 collision 强度是否呈右偏/集中分布。

Experiment 4: Lambda sensitivity
验证 collision penalty lambda_col 的性能-碰撞 trade-off。

Experiment 5: Tracking，可选
验证预测误差和闭环跟踪下 collision-aware assignment 是否仍然有效。
```

主文 baseline 建议收敛为五个，避免把重点稀释：

| Method | 关掉了什么 | 证明什么 |
|---|---|---|
| `random` | 关掉全部结构信息 | 最低可行基线 |
| `global_utility` | 只最大化观测效用，不考虑 collision 耦合 | 收益不是来自“全局优化更强”，而是来自 collision-aware |
| `box_dd` | 用盒式 DD overlap 替代 Dirichlet 泄漏 | 证明 fractional Doppler / Dirichlet 泄漏建模有必要 |
| `dd_only` | 只用 Dirichlet DD 泄漏，关掉角度重叠 | 证明 angle 维度有价值 |
| `proposed` | 使用 Dirichlet DD-angle collision | 本文方法 |

`nearest` 和 `strongest` 保留在补充实验中。如果在你的场景中两者产生几乎相同的分配，主文不同时展示，避免重复 baseline 稀释贡献。

小规模最优性参照建议另做 `ILP/oracle`，不进主表，只报告 greedy optimality gap。

Gate 2 不再使用不可达的三体制分类。主文采用两类 collision-density 标签：

```text
rho_col < regime_i_max      -> low collision
rho_col >= regime_i_max     -> sparse collision
```

不要把“heavy-tail”按在 `rho_col` 上。`rho_col` 描述的是碰撞有多少，主文只报告其稀疏性和随 `M/Q` 的趋势。尾部/集中性应针对归一化碰撞强度 `C_norm` 报告：

```text
skew_C_norm
excess_kurt_C_norm
max_to_mean_C_norm
eta_top_norm
```

推荐表述为：

```text
Collisions are sparse in density, while their normalized strengths are right-skewed:
a small fraction of task-edge interactions contributes a disproportionate amount of collision energy.
```

Hill tail index 不在主文默认报告。若需要尾部指数，只使用：

```text
gate2_pooled_hill_summary.csv
```

即把所有 trial 的 per-edge `C_norm` 汇集后，对 top 5% / 10% / 20% 三个截断比例分别估计。不要使用 per-trial Hill 再平均的数值作为正文结论，因为单个 deployment 内样本量有限，估计不稳定。

角度维的作用用：

```text
angle_removed_frac = (N_DD - N_DDA) / N_DD
```

来量化，即 DD-only 判定出的碰撞中有多少被 angle overlap 识别为可分辨伪碰撞。

其中 `Proxy validation` 是论文可信度的关键实验。每个受保护任务边 `(j,q)` 作为一个样本点：

```text
横轴：log10(Cbar_proxy)
纵轴：Delta Pd = Pd(clean) - Pd(collision)
```

并报告 Pearson/Spearman 相关系数及 bootstrap 95% CI。如果该相关性不显著，说明优化代理和真实链路损失脱节，需要重新定义 `Omega_DD` 或 `Cbar`。

更严格地，输出还包含扣除 clean-link SCNR 后的偏相关：

```text
partial corr(log10(Cbar), Delta Pd | SCNR_clean)
```

该指标用于排除“只是 SNR 同时影响 Cbar 和 Pd”的混淆。建议论文中过关标准写为：

```text
Spearman rho >= 0.7
bootstrap 95% CI lower bound > 0.5
partial Spearman after controlling SCNR_clean >= 0.5
```

同时检查：

```text
cbar_delta_pd_binned.csv
```

确认 `log10(Cbar)` 分箱后的 `Delta Pd` 条件均值整体单调上升。

如果：

```text
cbar_delta_pd_diagnostics.csv
```

中出现大量 `Cbar_proxy ~= 0` 但 `Delta Pd > 0.02` 的样本，通常说明 Dirichlet 泄漏核没有真正接入，或者某处提前把 fractional Doppler bin 取整了。
