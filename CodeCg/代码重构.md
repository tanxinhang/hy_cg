# 代码重构说明

原始 `gate_otfs_collision_experiments_v18.py` 已拆分为 `gate_otfs_collision/` 包，原文件保留为兼容入口。

## 模块结构

- `gate_otfs_collision/config.py`：仿真配置、参数列表解析、全局常量。
- `gate_otfs_collision/scenario.py`：几何工具、场景数据结构、场景生成。
- `gate_otfs_collision/kernels.py`：DD/OTFS 核、重叠度、信号模板。
- `gate_otfs_collision/assignment.py`：可见性、碰撞边、分配算法、目标函数。
- `gate_otfs_collision/detection.py`：独立链路检测评估。
- `gate_otfs_collision/experiments.py`：Gate 1/2、补充实验、预测鲁棒性、跟踪实验。
- `gate_otfs_collision/cli.py`：命令行参数与实验调度。

## 运行方式

旧方式仍可用：

```powershell
python .\gate_otfs_collision_experiments_v18.py --help
```

也可以使用包入口：

```powershell
python -m gate_otfs_collision --help
```
